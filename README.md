# MNSTK
A SaaS platform that empowers teachers and instructors to create and manage their own online academies, publish courses, manage students, and deliver educational content.

## Core Features

- Academy creation and customization
- Course and lesson management
- Student enrollment and management
- Online learning experience
- Payments and subscription management
- Instructor dashboard and analytics

## Technology Stack

- Backend: ASP.NET Core Web API
- Frontend: To be determined
- Database: SQL Server
- Version Control: Git and GitHub

## Project Status

Planning and development.

## Vision

Make it easy for educators to launch and grow their own online academies without building a website from scratch.
